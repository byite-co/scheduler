## 1. 개요
독립 **과외쌤**과 **학생**을 잇는 입시 공부관리 서비스. 학생은 *열품타급 습관 앱*으로 매일 공부하고,
과외쌤은 *데스크톱형 관리도구*로 숙제·검사·리포트를 운영한다. (자매 서비스 쌤버십=멘토 마켓은 **범위 밖**, 환류 진입점만 존재.)

## 2. 사용자 & 앱 구조
- **학생 앱**(모바일/태블릿) — 따뜻·경쾌. 단일 앱이며, **혼공생/과외생은 별도 앱이 아니라 "연결 상태" 차이**다.
- **과외쌤 앱**(데스크톱 우선·태블릿·모바일) — 중립 프로 SaaS. 학생을 초대코드로 연결해 관리.
- 두 앱은 하나의 백엔드(Supabase)를 공유하고, **연결(connection)**로 이어진다.

## 3. 핵심 가치 / 차별점
1. **공부 타이머 + 연속(streak) 습관** — 과목별 세션 기록, 연속일, 또래 비교.
2. **AI 완료검사** — 제출 사진을 보고 **통과/미흡/애매 + 확신도 + 사유**. *채점이 아니라 "다 했는지" 확인.*
3. **입시데이터 기반 AI 공부량 추천** — 비슷한 학생 코호트의 과목별 주간 시간 + 사유.
4. **AI 리포트 초안** — 주간 데이터 → 선생님 코멘트 초안(과외쌤이 검토·발송).
5. **집중 모드** — **온디바이스 졸음 감지**(포그라운드 전용, **영상은 기기를 떠나지 않음**), 집중률·졸음 메타데이터만 저장.
6. **쌤버십 환류** — 혼공생에게 멘토 연결 진입점 노출(강요 X).

## 4. 도메인 규칙 (구현 시 자주 틀림 — 반드시 준수)
- **혼공생 vs 과외생**: `connections`에 `status='active'`가 있으면 과외생.
  - *혼공 홈*: "선생님 숙제" 섹션 없음, "우리 반" 대신 또래 랭킹, 모든 할 일의 AI 검사는 **학생이 토글**.
  - *과외생 홈*: 선생님 숙제 표시, 우리 반 표시.
- **AI 검사 결정권**: 본인 할 일 → 학생 토글 / **선생님 숙제 → 과외쌤이 출제 때 결정(학생 잠금)**.
- **공개 범위(disclosure)**: **학생이 통제, 과외쌤은 읽기 전용.** 과외쌤이 보는 학생 데이터는 disclosure로 필터.
- **AI 검사 결과**: 과외생=선생님 코멘트 포함 / **혼공생=AI 단독(선생님 언급 없음).**
- **연결 핸드셰이크**: 한 번에 하나의 상태(pending/active/rejected). 학생이 코드 입력→과외쌤 수락→active.
- **streak**: 하루 놓쳐도 비난 금지, 회복 동선 제공.

## 5. 기능별 정의
### 5.1 인증·온보딩·연결
가입(소셜+이메일)·이메일 인증·비밀번호 찾기/재설정. 학생 J1~J4 / 과외쌤 A1~A4. **만 14세 미만 보호자 동의.**
연결: 과외쌤이 초대코드 발급 → 학생이 입력 → 과외쌤 수락 → active. 거절/대기 상태 화면 존재. 연결 시 공개범위 동의(G6).

### 5.2 홈(오늘)
과외생/혼공/제로(첫 사용) 3변형. 히어로(오늘 공부시간·목표·공부 시작·집중 모드), 할 일, (과외생)선생님 숙제·우리 반 / (혼공)또래 랭킹. streak 표시.

### 5.3 플래너·시간표·기록
할일/시간표(일·주)/캘린더. 할 일 CRUD + 과목 + AI 검사 토글(본인)/잠금(선생님 숙제). 공부 기록(누적·추이). 혼공/제로 변형.

### 5.4 타이머·집중 모드
과목 선택 타이머 → 세션 저장(누적·streak). 집중 모드: 카메라 권한 → 온디바이스 졸음 감지(포그라운드, 무업로드) → 졸음 환기 → 세션 요약 → 집중 리포트. **"영상은 기기를 떠나지 않아요" 노출.** 권한 거부 시 타이머만 폴백.

### 5.5 숙제·AI 완료검사
제출(사진) → AI 판정(통과/미흡/애매+확신도+사유). **과외생**: 쌤 확인(확인/반려/다시 제출) → 결과(선생님 코멘트). **혼공생**: 쌤 단계 없이 AI 단독 결과. 반려 시 "다시 제출 요청" 진입 → 재제출. 업로드/검사 실패 상태.

### 5.6 AI 추천·리포트
AI 공부량 추천 → "플래너에 반영". 학생 나의 리포트(주간 집계). 과외쌤 수업/주간 리포트 빌더(차트+AI 초안+담을 과목+코멘트) → 학부모 발송(공유 링크/카톡/PDF) → 학부모 웹뷰 + 히스토리 + 링크 만료. **무료=광고 보상 언락 / 프리미엄=무제한**(나의 리포트·AI 추천·혼공 AI 검사).

### 5.7 결제·구독 (★ 두 모듈 별개)
- **학생 프리미엄** ₩8,900/월 = 모바일 IAP. 무료→광고 보상 언락→프리미엄.
- **과외쌤 앱 구독료** = **연결 학생당 ₩4,900/월(웹 결제·Stripe)**. 월 청구 = `active 연결 수 × 4900`. 학생 연결 해제 시 다음 청구에서 감소. 결제 실패·미납 시 기능 제한→복구. 해지·일시정지 지원.
- **수업·수업료** = 학생이 과외쌤에게 내는 과외비의 **수기 트래커(결제 처리 아님)**. 앱 구독료와 **완전히 별개**.

### 5.8 알림·계정·시스템
푸시 권한 프라이밍/거부 + 알림 센터(딥링크). 계정 설정·프로필 편집·약관 뷰어·**회원 탈퇴(다단계·영구 삭제)**. 시스템 상태: 네트워크 오류·강제 업데이트·점검 중·첫 사용 코치마크.

## 7. 프라이버시 · 안전
- **집중 모드 영상은 기기를 떠나지 않음**(서버/Storage 저장 금지, 메타데이터만).
- 공개범위는 학생 통제·과외쌤 읽기 전용(RLS/뷰로 강제).
- 만 14세 미만 보호자 동의(획득·철회·차단·기록). 회원 탈퇴/삭제(영구·복구 불가 고지). PIPA·앱스토어 준수.
- 미성년 대상 부적절 콘텐츠 없음.

## 8. 비기능
- **디자인 토큰**: 인디고 #3D5AFE 기본 / 불꽃 #FF6B3D는 '지금·시작·연속·긴급'에만 / 잉크·서브·캔버스·성공·경고·위험(AGENTS.md §5). Pretendard, 시간 tabular-nums, 칩 nowrap.
- **이중 톤**: 학생=따뜻 / 과외쌤=중립 프로 SaaS.
- **접근성**: WCAG AA(4.5:1), 상태를 색만으로 전하지 않음.
- 화면 기준은 `docs/ui-catalog/` PNG(레이아웃·카피·상태).
